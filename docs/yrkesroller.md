## Vad är skillnaden?

Jag har valt att prata om IT säkerhetstekniker och Cybersäkerhetstekniker

Som jag förstår det så sköter IT säkerhetstekniker den dagliga driften där dem kontrollerar att nätverksvägar, firewalls och anti-virus är under kontroll, uppdaterade och i drift.
Det är också IT säkerhetsteknikerna som sköter och kontrollerar att loggarna är intakta och inte har blivit manipulerade samt kontrollerar att personer inom företaget har rätt rättigheter för den roll den behöver, inte mer, inte mindre.

Som Cybersäkerhetstekniker tar man en mer proaktiv och hands on approach till säkerhet där dem ofta kör penetrationstester för att kunna hitta svagheter i strukturen där attackerare kan tänkas attackera för att sedan skapa rapportera detta vidare. Dem analyserar skadlig kod samt kan utbilda personal vid mindre företag om risker och problem som kan uppstå så som phishing eller skadliga program som kan laddas ned på företags telefoner eller datorer.

Då båda jobbar mot samma mål så skiljer dem sig åt och jag känner att jag skulle vilja utbilda mig för att kunna jobba som antingen eller, men cybersäkerhet är säljpunkten för mig och något jag vill lära mig mer om!
