Scenario
-------------------------
Ett företag använder e-post, Microsoft 365, mobiltelefoner och ett HR-system

E-post

E-post har vissa svagheter både vid mänsklig faktor men också på nätet. 
| Hot: | sårbarheter: | Lösningar: |
|---|---|---|
| Target för cyberattacker| Social engineering så som phising eller osäkerhet om autentisitet | Utbilda personal att hot finns både utifrån men också innifrån och att dem bör tänka extra angående filer eller länkar som skickas. |
| Lättåtkomligt lösenord | Konversationer och kännslig information kan läcka ut | Det skall både vara enkelt för personal att komma åt sin mail men svårt för andra att komma åt, MFA är ett bra exempel |
| Kan påverka policys och intigritet | Som bas, okrypterat | Möjlighet för att kunna kryptera känslig information som skickas mellan personer så som 2 key enkryption |


Microsoft 365

Microsoft har sina brister ibland och folk som angriper är medvetna om dessa
| Hot: | sårbarheter: | Lösningar: |
|---|---|---|
| Hot mot intigritet och viktig data | Autentiserings problem | Behöver uppdateras ofta | Autentiserings problem kan lösas så som med MFA eller något som är kopplat till ens jobbprofil som mobilnummer, jobbprofilens biometrics eller kontonamn för spårbarhet
| Data breach, när jag säger data breach tänker jag direkt på möjligheten att fel personer finns på fel ställen och kan skapa problem både oavsiktligt eller avsikligt som kan kosta både tid och pengar för att få tillbaka | Data breach kan oftast lösas med att ge personen det dem behöver åtkomst till men inte mer än det. | Årlig omcertifiering kan tänkas vara ett alternativ, men skall inte kännas som en omväg eller omständighet för personal |
| Ransomware | Kan ha buggar som kan exploiteras av hackare som är medvetna om svagheterna | Uppdateringar kan oftast automatiseras och man kan få AI agenter till att hålla detta igång och skapa enkla patches som fixar sårbarheter på utdaterade maskiner |


Mobiltelefoner

| Hot: | sårbarheter: | Lösningar: |
|---|---|---|
| Stulna identiteter| Social engineering | Utbilda personer om hot som kan uppstå |
| Känslig mot attacker om hen är outbildad | Molntjänter, Wifi | Ge personen en jobb telefon endast gjord för MFA, biometrics |
| Läckage | utdaterad hård/mjuk -vara | Utbildning om säker surfning, vikten med säkert wifi och att inte koppla in på öppna nätverk som inte är statliga |


   
HR-system

| Hot: | sårbarheter: | Lösningar: |
|---|---|---|
| Autentiserings problem, är det rätt person på rätt plats? | Rätt rättigheter | Endast HR avdelningen har åtkomst, konton åt var HR representant för spårbarhet och autentisiering |
